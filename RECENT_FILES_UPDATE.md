# GITLS 2.40.7 — Recent Files Update

## Perubahan
- Recent Files sekarang menampilkan kartu file yang lebih jelas.
- Menampilkan tipe file, ukuran, waktu modifikasi, dan lokasi.
- Pencarian file terbaru secara langsung.
- Membuka file teks langsung di Editor GITLS.
- File non-teks dibuka memakai aplikasi Android yang sesuai melalui FileProvider.
- Menu tindakan per file: Buka, Bagikan, Hapus dari Recent, Detail.
- Bersihkan Recent Files memakai konfirmasi agar file asli tidak ikut terhapus.
- Refresh daftar Recent Files.
- Entri file yang sudah tidak ada otomatis dibersihkan dari daftar.
- Ikon kategori sederhana tetap mengikuti UI monokrom hitam-putih GITLS.
- Batas riwayat tetap maksimal 20 file.

## Catatan
Recent Files hanya menyimpan daftar shortcut/path file yang pernah digunakan. Membersihkan Recent Files tidak menghapus file asli.
