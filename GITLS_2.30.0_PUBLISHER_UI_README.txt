GITLS 2.30.0 Publisher UI Redesign — v7

v8 (partial final polish — shared design system pass)
- New DesignSystem.kt (object Ds): spacing, radius, touch target 48dp, animation durations, status colors (success/warning/error/info) for Light/Dark.
- visualTheme() now follows the active Light/Dark tokens (previously fixed light colors made inputs/buttons unreadable in dark mode).
- edit(): 56dp min height, 2dp focus border, responsive multiline height, contentDescription from hint.
- button(): ripple feedback, 3-level hierarchy (primary / secondary / tertiary), automatic secondary style for Copy/Clear/Reset/Cancel-type actions, wrap-content height for text scaling.
- compactButtonRow(): first action primary, others secondary.
- output(): result card with success status color, monospace for code-like output, 48dp Copy / Share / Clear actions.
- toolStatus(): colored status dot; subtitles never below 12sp.
- New reusable stateCard()/addEmptyState() for Loading / Success / Error(+Retry) / Empty.
NOT done in this pass: per-screen redesign of Home, File Manager, Console, Security, Network, Favorites/Recent audit.
Build: not run — no Gradle/Kotlin toolchain or network in this environment.
