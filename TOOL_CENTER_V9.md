# MyTools Tool Center v9

## Main features
- Registry-driven tool catalog
- Search by name/category/ID
- Category chips generated automatically
- Favorites
- Hidden tools
- Per-tool action menu
- Long-press favorite shortcut
- Favorite/hidden counters
- Consistent tool cards

## How to add a new tool
1. Add `ToolInfo` to `tools/ToolRegistry.kt`.
2. Implement or connect its existing MainActivity route.
3. It automatically appears in Tool Center.

No Tool Center UI changes are required for each new tool.
